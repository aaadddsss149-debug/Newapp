# Media assets

Put your screenshots and the demo video here. The project README files
(`README.md` / `README.ru.md`) reference these exact filenames:

| File | Used for |
| --- | --- |
| `demo.mp4` | App walkthrough video (keep it small, ideally < 10 MB) |
| `admin.png` | Admin dashboard (home page) |
| `history.png` | Order history screen |

If you rename files or add more screenshots, update the `<img>` / `<video>`
paths in `README.md` and `README.ru.md` accordingly.

> Tip: GitHub also lets you embed video by dragging the file into a comment/PR,
> which gives a `user-attachments` URL — handy if the inline `<video>` tag
> doesn't autoplay in your browser.
